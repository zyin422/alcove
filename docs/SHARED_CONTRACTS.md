# Shared System Contracts & Data Schemas
> **Interface Contract between Subgroup Alpha (M1) and Subgroup Beta (M3)**

To ensure Subgroup Alpha and Subgroup Beta can develop and test independently without merge conflicts or broken interfaces, both teams adhere strictly to these shared JSON schemas.

---

## 1. Loop Bridge: `data/session_state.json`
* **Written by:** Subgroup Beta (Milestone 3 — Ledger Debrief at Night)
* **Read by:** Subgroup Alpha (Milestone 1 — Launchpad Staging in the Morning)

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "SessionState",
  "type": "object",
  "properties": {
    "session_date": { "type": "string", "format": "date", "example": "2026-10-11" },
    "user_name": { "type": "string", "example": "Alex" },
    "active_priorities": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "id": { "type": "string", "example": "task_1" },
          "title": { "type": "string", "example": "Build Auth Middleware & JWT Verification" },
          "target_repo_path": { "type": "string", "example": "src/middleware/auth.py" },
          "verification_criteria": { "type": "string", "example": "Pass unit tests for auth and token decoding" },
          "status": { "type": "string", "enum": ["PENDING", "IN_PROGRESS", "CARRIED_OVER"], "example": "PENDING" },
          "prep_notes": { "type": "string", "example": "Generate boilerplate test fixture with mocked payload" }
        },
        "required": ["id", "title", "target_repo_path", "verification_criteria", "status"]
      }
    },
    "distraction_blacklist": {
      "type": "array",
      "items": { "type": "string" },
      "example": ["Discord", "Steam", "Twitter", "Reddit"]
    },
    "last_updated_at": { "type": "string", "format": "date-time" }
  },
  "required": ["session_date", "user_name", "active_priorities", "distraction_blacklist"]
}
```
