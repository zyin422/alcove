# In-App Updates (Sparkle) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tofu updates itself through Sparkle: a pop-up card above Stats in the sidebar offers new versions, and `scripts/release.sh` publishes them.

**Architecture:** Sparkle 2 (SPM) runs in "gentle reminders" mode: scheduled checks report a found update to a pure, tested `UpdateCenter` (owned by `AppModel`), which drives a SwiftUI card in the sidebar; the card's Update button hands back to Sparkle's standard window. A bash release script builds a secret-free Release build, zips and signs it, and publishes the zip + appcast to the public repo `axion66/tofu-releases`.

**Tech Stack:** Swift 5 / SwiftUI / Observation, macOS 14, XcodeGen 2.46+, Sparkle 2.10.0, XCTest, bash, `gh`.

**Spec:** `docs/superpowers/specs/2026-10-15-auto-update-design.md`

## Review Focus

1. A release build that still contains `.env` or `.env.local` content → the release script must abort before publishing (Task 5 verify step; Task 1 manual check).
2. The user dismisses the card, then the daily check finds the same version again → card must stay hidden for that version this run, but a newer version shows (Task 2 tests `testDismissedVersionStaysHidden`, `testNewerVersionShowsAfterDismiss`).
3. Sparkle's own window takes focus (user clicked Update or the menu) → card must disappear and not linger next to the window (Task 2 `testCheckNowHidesCardAndAsksDriverOnce`, `testHideDoesNotDismiss`).
4. Running tests or a Debug build → no Sparkle updater started, menu item disabled, no crash (Task 2 `testWithoutDriverCannotCheck`, Task 3 `#if !DEBUG` wiring).
5. Releasing from a dirty tree or reusing the current version number → script refuses before changing anything (Task 5 Step 2 checks).

```swift
import Observation

/// Starts Sparkle's update window. SparkleUpdater in release builds; a fake in tests.
@MainActor protocol UpdateDriving: AnyObject {
    func checkForUpdates()
}

/// What the sidebar's update card shows. Sparkle reports an update found by its daily check here instead of opening
/// its own window; the card's Update button and the Check for Updates menu item hand back to Sparkle.
@Observable @MainActor final class UpdateCenter {
    /// Nil in tests and Debug builds, where Sparkle never starts.
    var driver: (any UpdateDriving)?
    /// The version on the card; nil hides the card.
    private(set) var availableVersion: String?
    /// The version the user closed the card for. In memory only, so a relaunch shows it again.
    private var dismissedVersion: String?

    var canCheckForUpdates: Bool { driver != nil }

    init(driver: (any UpdateDriving)? = nil) {
        self.driver = driver
    }

    func updateFound(version: String) {
        guard version != dismissedVersion else { return }
        availableVersion = version
    }

    /// × on the card: hide it and skip this version until the next launch.
    func dismiss() {
        if let availableVersion { dismissedVersion = availableVersion }
        availableVersion = nil
    }

    /// Opens Sparkle's window, which takes over from the card.
    func checkNow() {
        availableVersion = nil
        driver?.checkForUpdates()
    }

    /// Sparkle has the user's attention or finished its session; the card goes without counting as dismissed.
    func hide() {
        availableVersion = nil
    }
}
```

```swift
import Sparkle

/// Runs Sparkle with gentle reminders: an update found by the daily check goes to the sidebar card (UpdateCenter)
/// instead of a window. The card's Update button and the Check for Updates menu item open Sparkle's window, which
/// downloads, verifies, installs and relaunches. Sparkle calls the delegate on the main thread.
@MainActor final class SparkleUpdater: NSObject, UpdateDriving, SPUStandardUserDriverDelegate {
    /// The center owns this updater (as its driver), so this side doesn't retain it.
    private unowned let center: UpdateCenter
    private var controller: SPUStandardUpdaterController!

    init(center: UpdateCenter) {
        self.center = center
        super.init()
        controller = SPUStandardUpdaterController(startingUpdater: true, updaterDelegate: nil, userDriverDelegate: self)
    }

    func checkForUpdates() {
        controller.checkForUpdates(nil)
    }

    nonisolated var supportsGentleScheduledUpdateReminders: Bool { true }

    nonisolated func standardUserDriverShouldHandleShowingScheduledUpdate(_ update: SUAppcastItem,
                                                                          andInImmediateFocus immediateFocus: Bool) -> Bool {
        false
    }

    nonisolated func standardUserDriverWillHandleShowingUpdate(_ handleShowingUpdate: Bool, forUpdate update: SUAppcastItem,
                                                               state: SPUUserUpdateState) {
        guard !handleShowingUpdate else { return }
        let version = update.displayVersionString
        MainActor.assumeIsolated { center.updateFound(version: version) }
    }

    nonisolated func standardUserDriverDidReceiveUserAttention(forUpdate update: SUAppcastItem) {
        MainActor.assumeIsolated { center.hide() }
    }

    nonisolated func standardUserDriverWillFinishUpdateSession() {
        MainActor.assumeIsolated { center.hide() }
    }
}
```

```bash
# Needs: xcodegen; gh logged in as a user who can push to the releases repo; the "Accountabilibrosis Local Codesign"
# certificate and Sparkle's EdDSA key (generate_keys) in this Mac's login Keychain.
set -euo pipefail

RELEASES_REPO="axion66/tofu-releases"
DOWNLOAD_PREFIX="https://raw.githubusercontent.com/${RELEASES_REPO}/main/"

TOFU_DIR="$(cd "$(dirname "$0")/.." && pwd)"
cd "$TOFU_DIR"

die() { echo "release: $*" >&2; exit 1; }

BUMPED=0
STAGE=""
cleanup() {
  local status=$?
  if [ -n "$STAGE" ]; then rm -rf "$STAGE"; fi
  if [ "$status" != 0 ] && [ "$BUMPED" = 1 ]; then
    echo "release: failed after bumping the version. Undo with: git checkout -- project.yml Tofu.xcodeproj" >&2
  fi
}
trap cleanup EXIT

DRY_RUN=0
if [ "${1:-}" = "--dry-run" ]; then
  DRY_RUN=1
  shift
fi
VERSION="${1:-}"
NOTES="${2:-}"

setting() { awk -F'"' -v key="$1" '$1 ~ "^ *" key ": *$" { print $2; exit }' project.yml; }
CURRENT_VERSION="$(setting MARKETING_VERSION)"
CURRENT_BUILD="$(setting CURRENT_PROJECT_VERSION)"
[ -n "$CURRENT_VERSION" ] && [ -n "$CURRENT_BUILD" ] || die "could not read MARKETING_VERSION / CURRENT_PROJECT_VERSION from project.yml"

if [ "$DRY_RUN" = 1 ]; then
  VERSION="$CURRENT_VERSION"
  BUILD="$CURRENT_BUILD"
else
  [[ "$VERSION" =~ ^[0-9]+(\.[0-9]+){1,2}$ ]] || die "usage: scripts/release.sh <version like 1.2> [notes]   or   scripts/release.sh --dry-run"
  [ "$VERSION" != "$CURRENT_VERSION" ] || die "$VERSION is already the current version"
  { git diff --quiet && git diff --cached --quiet; } || die "commit or stash your changes first; a release must match a commit"
  BUILD=$((CURRENT_BUILD + 1))
  BUMPED=1
  sed -i '' -E "s/^( *MARKETING_VERSION: ).*/\1\"$VERSION\"/; s/^( *CURRENT_PROJECT_VERSION: ).*/\1\"$BUILD\"/" project.yml
  xcodegen generate --quiet
fi

DERIVED="$TOFU_DIR/build/ReleaseData"
echo "release: building Tofu $VERSION ($BUILD)…"
xcodebuild -project Tofu.xcodeproj -scheme Tofu -configuration Release -destination 'platform=macOS' \
  -derivedDataPath "$DERIVED" TOFU_RELEASE=1 clean build -quiet
APP="$DERIVED/Build/Products/Release/Tofu.app"
[ -d "$APP" ] || die "the build produced no Tofu.app"

# The zip is public: it must carry no Discord token or OpenAI key.
[ ! -e "$APP/Contents/Resources/discord.env" ] || die "the build bundled discord.env; release builds must carry no secrets"
plist() { /usr/libexec/PlistBuddy -c "Print :$1" "$APP/Contents/Info.plist" 2>/dev/null; }
[ "$(plist CFBundleShortVersionString)" = "$VERSION" ] || die "built version is $(plist CFBundleShortVersionString), expected $VERSION"
[ "$(plist CFBundleVersion)" = "$BUILD" ] || die "built build number is $(plist CFBundleVersion), expected $BUILD"
[ -n "$(plist SUPublicEDKey)" ] || die "the built Info.plist has no SUPublicEDKey"
codesign --verify --deep --strict "$APP" || die "the code signature check failed"

GENERATE_APPCAST="$(find "$DERIVED/SourcePackages/artifacts" -path '*/bin/generate_appcast' -type f | head -n 1)"
[ -n "$GENERATE_APPCAST" ] || die "Sparkle's generate_appcast was not found under $DERIVED/SourcePackages/artifacts"

STAGE="$(mktemp -d)"
ZIP="Tofu-$VERSION.zip"
ditto -c -k --sequesterRsrc --keepParent "$APP" "$STAGE/$ZIP"
if [ -n "$NOTES" ]; then
  ESCAPED="$(printf '%s' "$NOTES" | sed -e 's/&/\&amp;/g' -e 's/</\&lt;/g' -e 's/>/\&gt;/g')"
  printf '<p>%s</p>\n' "$ESCAPED" > "$STAGE/Tofu-$VERSION.html"
fi

if [ "$DRY_RUN" = 1 ]; then
  RELEASES_DIR="$TOFU_DIR/build/release-dry-run"
  rm -rf "$RELEASES_DIR"
  mkdir -p "$RELEASES_DIR"
else
  RELEASES_DIR="$TOFU_DIR/build/tofu-releases"
  if ! gh repo view "$RELEASES_REPO" >/dev/null 2>&1; then
    echo "release: creating public repo $RELEASES_REPO…"
    gh repo create "$RELEASES_REPO" --public --description "Tofu app updates (Sparkle feed)" >/dev/null
  fi
  rm -rf "$RELEASES_DIR"
  gh repo clone "$RELEASES_REPO" "$RELEASES_DIR" -- --quiet
  # generate_appcast moves superseded archives into old_updates/; they don't need to be served.
  if [ ! -f "$RELEASES_DIR/.gitignore" ]; then echo "old_updates/" > "$RELEASES_DIR/.gitignore"; fi
fi

cp "$STAGE/$ZIP" "$RELEASES_DIR/"
if [ -f "$STAGE/Tofu-$VERSION.html" ]; then cp "$STAGE/Tofu-$VERSION.html" "$RELEASES_DIR/"; fi
"$GENERATE_APPCAST" --download-url-prefix "$DOWNLOAD_PREFIX" --embed-release-notes "$RELEASES_DIR"

if [ "$DRY_RUN" = 1 ]; then
  echo "release: dry run done; nothing was published. Archive and appcast: $RELEASES_DIR"
  sed -n '/<item>/,/<\/item>/p' "$RELEASES_DIR/appcast.xml"
  exit 0
fi

git add project.yml Tofu.xcodeproj
git commit --quiet -m "chore: release $VERSION"
BUMPED=0
git -C "$RELEASES_DIR" add -A
git -C "$RELEASES_DIR" commit --quiet -m "Tofu $VERSION"
git -C "$RELEASES_DIR" push --quiet origin HEAD:main \
  || die "pushing $RELEASES_REPO failed; retry with: git -C $RELEASES_DIR push origin HEAD:main && git tag v$VERSION"
git tag "v$VERSION"
echo "release: published Tofu $VERSION ($BUILD). Friends get it within a day, or via Tofu > Check for Updates…"
echo "release: the source repo was not pushed. When ready: git push && git push origin v$VERSION"
```

- [ ] **Step 3: Add the README section** — insert after the `## Build and run` section (before `## Permissions`):

````markdown
## Updates

Tofu updates itself with [Sparkle](https://sparkle-project.org). Once a day it checks
`https://raw.githubusercontent.com/axion66/tofu-releases/main/appcast.xml`. When a newer version exists, a card appears
above **Stats** in the sidebar: **Update** opens Sparkle's window (release notes → Install → relaunch), **×** hides it
until the next launch. **Tofu → Check for Updates…** checks right away. Debug builds never check.

**For friends (first install):**
1. Download the newest `Tofu-<version>.zip` from [axion66/tofu-releases](https://github.com/axion66/tofu-releases),
   unzip it and move `Tofu.app` to Applications.
2. The first launch is blocked because the app isn't notarized: open **System Settings → Privacy & Security** and click
   **Open Anyway**. Updates after that install without this step.
3. Release builds carry no keys. Paste the Discord bot token (ask the maintainer) and, optionally, your own OpenAI key
   in **Settings**. They live in your Keychain and survive updates.

**For the maintainer (publishing):**

```bash
cd Tofu
scripts/release.sh --dry-run              # build + sign + appcast locally, publishes nothing
scripts/release.sh 1.2 "What changed"     # bump, build, publish to axion66/tofu-releases, commit + tag (no source push)
```

The script refuses a dirty tree or a reused version number, and aborts if the build would ship `discord.env`.
It needs, on this Mac only:
- the **Accountabilibrosis Local Codesign** certificate — every release must be signed with it, or friends lose
  their Accessibility grant after updating;
- Sparkle's private EdDSA key in the login Keychain (created once with `generate_keys`; its public half is
  `SUPublicEDKey` in `project.yml`). Back it up:
  `build/ReleaseData/SourcePackages/artifacts/sparkle/Sparkle/bin/generate_keys -x ~/tofu-sparkle-key.txt`
  and keep the file somewhere safe. Without it, friends' copies can't verify new updates and must be reinstalled.
````
